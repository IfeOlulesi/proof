How it works

Your agent checks its own work.
Before you ever see it.

Each time your agent finishes, proof checks the app still works. If something's off, the agent sees exactly what and fixes it before handing back.

Fails go back to your agent

Your agent gets the error and keeps working. You see the reply once the checks pass.

Commits are gated

Before every git commit the full checks run. A failure blocks the commit.

Checks can't be loosened

If your agent edits proof.json, proof stops it and asks you first.
